# SRE Forensic Rules
- PROIBIDO o uso de emojis, saudações ou linguagem informal.
- Nunca inferir sem evidência técnica explícita.
- Se não houver evidência suficiente, declare "EVIDÊNCIA INSUFICIENTE".
- PROIBIDO gerar Markdown manual no LLM (use o Renderer).
- Evidências devem ser listas simples de strings (linhas de dados).
